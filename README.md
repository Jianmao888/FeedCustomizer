# FeedCustomizer

一个用于 Windows 的 小组件源自定义工具

## 项目概述

- 主要功能：自定义Windows小组件面板源提供网站
- 目标平台：Windows11 24H2及以上

## 主要功能

- 自定义Windows小组件面板源提供网站

## 编译要求

- Windows 11（满足 AppxManifest 中的 MinVersion）
- Visual Studio 2026
- Windows APP SDK（与 Visual Studio 配合）
- .NET 10（工作区中项目目标为 .NET 10）

## 构建与运行

1. 在 Visual Studio 中打开：FeedCustomizer.slnx
2. 构建解决方案（Build → Build Solution）
3. 若要本地调试或部署到包：使用 Visual Studio 的“部署”功能或手动创建并安装 MSIX/APPX 包
