源自定义工具 · 帮助文档

使用本工具前，请了解以下功能及其适用条件。开发者选项和地区限制均可在应用的“设置 → 高级”中处理。
功能 1 自动启用开发者选项

启用设置中的“自动启用开发者选项”后，应用每次安装自定义源时都会临时开启 Windows 开发者选项，完成操作后自动关闭。

  • 打开本工具的 设置 → 高级。
  • 开启 自动启用开发者选项 配置即可，无需每次手动切换系统设置。
  • 关闭此配置后，如需继续注册自定义源，则需要按照 Windows 的提示手动开启开发者选项。
Windows 系统设置中的名称可能显示为“开发者模式”或“开发者选项”
⚠️ 安全提示： 开发者选项可能会降低设备安全性。应用只会在执行需要该权限的操作期间临时开启，完成后自动恢复原状态。
关闭开发者选项后，已添加的自定义源依旧会正常显示，不影响已有功能。
功能 2 解除自定义源地区限制

如果当前设备的“设备设置地区”不是欧盟成员国，可以使用设置中的“解除自定义源地区限制”功能，强制允许显示第三方自定义源。

  • 打开本工具的 设置 → 高级。
  • 点击 解除限制，确认警告并按提示授予管理员权限。
  • 修改成功后，重启小组件，或注销并重新登录 Windows，使配置生效。
⚠️ 风险提示： 此功能会通过修改 Windows 系统配置的方式强行开启自定义源显示，可能影响系统相关功能或稳定性。请在确认理解风险后再使用，并确保重要数据已有备份。
系统更新可能会覆盖此修改，导致地区限制恢复；如需继续使用，可能需要重新执行解除限制操作。
手动修改设备设置区域： Windows 无法在系统设置中直接修改“设备设置地区”。如需修改，请参考以下博客的说明，使用终端命令进行操作： 修改Windows设备设置区域 · Lxn-Chan!
⚠️ 该博客并非由工具作者撰写，仅作为操作参考。请仔细阅读操作步骤，并自行评估风险。
功能 3 清除小组件网页数据

可在 设置 → 高级 中使用“清除数据”重置小组件面板网页保存的本地数据。

  • 确认警告后，应用会关闭当前小组件面板并清除其网页本地数据。
  • 清理范围包括缓存、登录状态、站点存储，以及由其他应用管理的源保存的数据。
  • 下次打开小组件面板时，Windows 会创建新的网页数据；如有云端同步，部分内容可能重新出现。
⚠️ 数据提示： 此操作不可撤销，且会影响其他应用管理的源。若小组件进程持续占用数据，应用会提示无法删除；请关闭小组件面板后重试。
