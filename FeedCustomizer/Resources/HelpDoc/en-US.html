Feed Customization Tool · Help

Before using this tool, please review the following features and their requirements. Developer options and region restrictions can be managed under “Settings → Advanced” in the app.
Feature 1 Automatically enable developer options

When “Automatically enable developer options” is enabled, the app temporarily enables Windows developer options each time a custom feed is installed, then automatically disables them after the operation is complete.

  • Open Settings → Advanced in this tool.
  • Enable the Automatically enable developer options setting; you do not need to switch the Windows setting manually each time.
  • If this setting is disabled, you must manually enable developer options when prompted by Windows to install a custom feed.
The Windows setting may be named “Developer Mode” or “Developer options”
⚠️ Security Notice: Developer options may reduce device security. The app enables them only temporarily while performing operations that require them, then restores the previous state.
After developer options are disabled, any custom feeds you have added will still display normally and existing functionality remains unaffected.
Feature 2 Remove custom feed region restriction

If the device's “Device region” is not set to an EU member state, you can use “Remove custom feed region restriction” in the settings to force-enable third-party custom feeds.

  • Open Settings → Advanced in this tool.
  • Click Remove restriction, confirm the warning, and grant administrator permission when prompted.
  • After the change succeeds, restart the widget, or sign out and sign back in to Windows, for the configuration to take effect.
⚠️ Risk Notice: This feature modifies Windows system configuration to force-enable custom feed display. It may affect related system functions or stability. Use it only after understanding the risks, and make sure important data is backed up.
A system update may overwrite this change and restore the region restriction. If you want to continue using the feature, you may need to remove the restriction again.
Manually change the device region: Windows does not provide a direct way to change “Device region” in System Settings. To change it, follow the instructions in the following blog post and use terminal commands: Change Windows device region · Lxn-Chan!
⚠️ This blog is not authored by the tool creator and is provided for reference only. Read the instructions carefully and assess the risks yourself.
