Feed Customization Tool · Help

Manage developer options, region restrictions, and Widgets web data under “Settings → Advanced”.
Feature 1 Automatically enable developer options

With “Automatically enable developer options” enabled, the app temporarily enables Windows developer options when installing a custom feed, then restores the previous state.

  1. Open “Settings → Advanced”.
  2. Turn on “Automatically enable developer options”.
  3. If this feature is off, enable developer options manually when prompted.
The Windows setting may be named “Developer Mode” or “Developer options”.
⚠️ Security notice: Developer options may reduce device security. The app enables them temporarily only when needed, then restores the previous state. Disabling developer options does not affect feeds you have already added.
Feature 2 Remove custom feed region restriction

If the device's “Device region” is not an EU member state, use this feature to allow third-party custom feeds in the Widgets board.

  1. Open “Settings → Advanced”.
  2. Click “Remove restriction”, confirm the warning, and grant administrator permission.
  3. After it succeeds, restart your PC, or sign out and sign back in to Windows.
⚠️ Risk notice: This feature modifies Windows system configuration and may affect related functions or stability. Understand the risks and back up important data before use. System updates may restore the region restriction, requiring you to remove it again.
Manually change the device region: Windows does not provide a direct way to change this in Settings. See Change Windows device region · Lxn-Chan!.
This blog is not written by the tool creator and is provided for reference only. Assess the risks yourself.
Feature 3 Clear Widgets web data

Use Settings → Advanced → “Clear data” to reset local data saved by web pages in the Widgets board.

  • After confirmation, the app closes the Widgets board and clears cache, sign-in state, site storage, and other web data, including data saved for feeds managed by other apps.
  • Windows creates fresh web data when you reopen the board. Content synchronized from the cloud may return.
⚠️ Data notice: This action cannot be undone and affects feeds managed by other apps. If the app reports that data is in use, close the Widgets board and try again.
Troubleshooting Feed fails to enable or does not appear

Try these steps in order. Stop once the issue is resolved:

  1. Remove the region restriction: Use “Settings → Advanced”, then restart your PC, or sign out and sign back in to Windows.
  2. Clean up and enable again: Turn off the “Custom feed” switch, enter %LOCALAPPDATA%\FeedCustomProvider in the File Explorer address bar, and delete all files and subfolders inside that folder. Then enable the feed again. The path is usually C:\Users\Username\AppData\Local\FeedCustomProvider. Delete only the contents of this folder.
  3. Reset the app: Right-click “Widget Feed Customizer” in the Start menu, select “More → App settings” (or “App settings” directly), and click “Reset”. Then configure and enable the feed again. Resetting clears local app data and settings; back them up first.

Feed missing on Windows 11 26H2 after removing the restriction with an older tool version

Repair system files first, then remove the restriction using the current tool version:

  1. Right-click Start and open “Terminal (Admin)”. Run these commands in order, waiting for the first to succeed before running the second: 
    DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
  2. After the repair completes, restart your PC and remove the region restriction using the current tool version.
  3. Restart your PC again, or sign out and sign back in to Windows, then check the feed.
Stay connected to the internet during repair and wait for the commands to finish before closing Terminal. See Microsoft's system file repair instructions.
