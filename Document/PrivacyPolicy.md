# FeedCustomizer - 隐私政策

## 收集的信息

FeedCustomizer 不会收集任何个人信息，也不会将任何信息发送到开发者所属的任何服务器。

但是，FeedCustomizer 需要网络权限，用于以下用途：

- 下载小组件源所需的网站图片；
- 检查捐献者版的购买/授权状态。

此外，Microsoft Store 和 Windows 应用宿主可能会收集使用情况数据，例如谁购买/使用了该应用以及崩溃报告。如果您在应用中打开指向其他网站的链接或加载来自其他网站的内容，您需要查阅相应网站的隐私政策。

## 捐献者版

为了检查捐献者版的购买/授权状态，FeedCustomizer 需要访问互联网。

为优化用户体验，FeedCustomizer 只会在您首次启动时检查捐献者版的购买/授权状态。

## 信息的使用

除上述用途外，FeedCustomizer 不会收集或在线共享任何其他数据。我们保留修改本政策的权利，对本政策的任何更改都会及时更新。
