源自定义工具 · 帮助文档

开发者选项、地区限制和小组件网页数据均可在“设置 → 高级”中管理。
功能 1 自动启用开发者选项

开启“自动启用开发者选项”后，应用会在安装自定义源时临时开启 Windows 开发者选项，完成后恢复原状态。

  1. 打开“设置 → 高级”。
  2. 开启“自动启用开发者选项”。
  3. 若关闭此功能，则需要按提示手动开启开发者选项。
Windows 中的名称可能显示为“开发者模式”或“开发者选项”。
⚠️ 安全提示： 开发者选项可能会降低设备安全性。应用仅在必要操作期间临时开启，完成后恢复原状态。关闭开发者选项不影响已添加的自定义源。
功能 2 解除自定义源地区限制

如果设备的“设备设置地区”不是欧盟成员国，可使用此功能允许小组件面板显示第三方自定义源。

  1. 打开“设置 → 高级”。
  2. 点击“解除限制”，确认警告并授予管理员权限。
  3. 成功后重启电脑，或注销并重新登录 Windows。
⚠️ 风险提示： 此功能会修改 Windows 系统配置，可能影响相关功能或稳定性。请理解风险并备份重要数据后使用。系统更新可能恢复地区限制，届时需要重新解除。
手动修改设备设置地区： Windows 无法在系统设置中直接修改此项，可参考 修改 Windows 设备设置区域 · Lxn-Chan!。
该博客并非工具作者撰写，仅供参考，请自行评估风险。
功能 3 清除小组件网页数据

在“设置 → 高级”中点击“清除数据”，可重置小组件面板网页保存的本地数据。

  • 确认后，应用会关闭小组件面板，并清除缓存、登录状态、站点存储等数据，包括其他应用管理的源保存的数据。
  • 再次打开面板时，Windows 会重新创建网页数据；云端同步的内容可能恢复。
⚠️ 数据提示： 此操作不可撤销，且会影响其他应用管理的源。若提示数据被占用，请关闭小组件面板后重试。
故障排查 启用失败或启用后不显示

请依次尝试，问题解决后即可停止：

  1. 解除地区限制：在“设置 → 高级”中解除限制，然后重启电脑，或注销并重新登录 Windows。
  2. 清理后重新启用：关闭“自定义源”开关，在文件资源管理器地址栏输入 %LOCALAPPDATA%\FeedCustomProvider，删除该文件夹内的所有文件和子文件夹，再重新启用自定义源。该路径通常为 C:\Users\用户名\AppData\Local\FeedCustomProvider，请仅清理此文件夹中的内容。
  3. 重置应用：在开始菜单中右键点击“资讯源自定义工具”，选择“更多 → 应用设置”（或直接选择“应用设置”），点击“重置”，完成后重新配置并启用。重置会清除应用本地数据和设置，请提前备份。

旧版工具解除限制后，Windows 11 26H2 中不显示

请先修复系统文件，再用当前版本工具重新解除限制：

  1. 右键点击开始按钮，打开“终端（管理员）”，依次执行以下命令，等待第一条成功完成后再执行第二条： 
    DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
  2. 修复完成后重启电脑，使用当前版本工具重新解除地区限制。
  3. 再次重启电脑，或注销并重新登录 Windows，然后检查自定义源。
修复期间请保持联网，等待命令完成再关闭终端。参考： 微软系统文件修复说明。
